# Prelove-fashion

Pre-loved fashion store (Thrice Loved) for the e-commerce module.

- `index.html` – the public website (served by GitHub Pages), with Google Analytics 4 events: `page_view`, `add_to_cart`, `begin_checkout`.
- `shopify-theme/` – the Shopify theme source (zip its contents to upload to Shopify).
- `store-data/` – `products.csv` for Shopify import and the product images.
- `tools/` – scripts that generate the images, CSV and site.
- `SETUP-GUIDE.md` – Shopify setup steps.
